## 🎮 ¿Qué es CapoGames?

CapoGames es una aplicación para macOS diseñada para reunir diferentes plataformas de juegos en una única biblioteca.

El objetivo es ofrecer una experiencia visual, sencilla y cómoda para navegar por tus juegos, descubrir contenido y utilizar la aplicación tanto con teclado y ratón como con mando.

Actualmente, CapoGames incluye integración con **Steam**, **Roblox** y **emuladores** de tu Mac.

---

## ✨ Características

* 🎮 Biblioteca de juegos de Steam.
* 🕹️ Integración con juegos de Roblox.
* 🖥️ Soporte de emuladores: añade tus emuladores y lanza ROMs desde CapoGames.
* ⭐ Sistema de favoritos (Steam, Roblox y emuladores).
* 🔍 Búsqueda de juegos.
* 🎯 Navegación optimizada para mando.
* 💾 Detección de juegos instalados de Steam.
* 🚀 Apertura directa de juegos compatibles.
* 🧩 Modo solo emuladores (sin necesidad de iniciar sesión).
* 🎨 Interfaz diseñada específicamente para una experiencia de biblioteca de juegos.
* 🔄 Actualizaciones y nuevas versiones publicadas mediante GitHub Releases.
* 🗑️ Opción para eliminar todos los datos de la app y empezar de cero.

---

## 🖥️ Plataformas

### Steam
CapoGames puede conectarse con tu cuenta de Steam y mostrar tu biblioteca de juegos.  
También puede detectar localmente qué juegos están instalados mediante la carpeta `steamapps`.

### Roblox
CapoGames permite explorar y añadir juegos de Roblox a tu biblioteca (favoritos y recientes).

### Emuladores
Puedes registrar emuladores instalados en tu Mac (PCSXR, RetroArch, Dolphin, OpenEmu, etc.), indicar la carpeta de ROMs y lanzar los juegos directamente desde CapoGames.

Formatos detectados habitualmente: `.iso`, `.bin`, `.cue`, `.chd`, `.nes`, `.sfc`, `.n64`, `.gba`, `.nds`, `.wbfs`, `.rvz` y muchos más.

No es obligatorio iniciar sesión con Steam o Roblox: puedes usar CapoGames **solo para emuladores**.

## 🎮 Uso con mando

CapoGames está diseñado para poder navegar cómodamente utilizando un mando compatible.

La interfaz permite:

* Desplazarse entre secciones (Juegos / Emuladores).
* Navegar por la biblioteca.
* Abrir el teclado virtual de búsqueda.
* Lanzar juegos y acceder a opciones (favoritos, etc.).
* Usar el menú del mando (incluido cerrar la app).
