## 🎮 ¿Qué es CapoGames?

CapoGames es una aplicación para macOS diseñada para reunir diferentes plataformas de juegos en una única biblioteca.

El objetivo es ofrecer una experiencia visual, sencilla y cómoda para navegar por tus juegos, descubrir contenido y utilizar la aplicación tanto con teclado y ratón como con mando.

Actualmente, CapoGames incluye integración con Steam y Roblox.

## ✨ Características

* 🎮 Biblioteca de juegos de Steam.
* 🕹️ Integración con juegos de Roblox.
* ⭐ Sistema de favoritos.
* 🔍 Búsqueda de juegos.
* 🎯 Navegación optimizada para mando.
* 💾 Detección de juegos instalados de Steam.
* 🚀 Apertura directa de juegos compatibles.
* 🎨 Interfaz diseñada específicamente para una experiencia de biblioteca de juegos.
* 🔄 Actualizaciones y nuevas versiones publicadas mediante GitHub Releases.

## 🖥️ Plataformas

### Steam

CapoGames puede conectarse con tu cuenta de Steam y mostrar tu biblioteca de juegos.

También puede detectar localmente qué juegos están instalados mediante la carpeta `steamapps`.

### Roblox

CapoGames permite explorar y añadir juegos de Roblox a tu biblioteca.

## 🎮 Uso con mando

CapoGames está diseñado para poder navegar cómodamente utilizando un mando compatible.

La interfaz permite desplazarse entre las diferentes secciones, navegar por los juegos y utilizar las funciones principales sin depender exclusivamente del ratón.
